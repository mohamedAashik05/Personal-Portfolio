# Mohamed Aashik I — Portfolio

Personal developer portfolio showcasing my projects, technical skills, and background as a Software Engineer and 2026 Computer Science and Business Systems graduate.

## 🛠️ Tech Stack

* **Frontend:** React, TypeScript, Vite, Tailwind CSS
* **Backend & Database:** Node.js, Express, .NET Core, Supabase, MongoDB, Microsoft SQL Server
* **Tools & Workflow:** Git, GitHub, Docker, VS Code

## 🚀 Key Features

* **Interactive Projects Showcase:** Highlighted breakdown of full-stack web and mobile applications (including AgriSmart and PromptCatalyst).
* **Responsive Design:** Built with Tailwind CSS for seamless viewing across mobile and desktop devices.
* **Clean Architecture:** Component-driven structure focused on maintainability and performance.

## 📁 Getting Started

To run this project locally:

```bash
# Clone the repository
git clone [https://github.com/mohamedAashik05/Personal-Portfolio.git](https://github.com/mohamedAashik05/Personal-Portfolio.git)

# Navigate to the project directory
cd Personal-Portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
